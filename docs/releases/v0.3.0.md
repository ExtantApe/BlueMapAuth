Works with Posse 0.11.0 (formerly Mayor); the Mayor name is no longer recognized (D196, D292).

## What changed

- **BlueMapAuth looks for the plugin `Posse` and no longer recognizes `Mayor`.** It reads who a viewer may see from Posse's `mayReach` and `sharesCircle`. An old Mayor jar left on a server is ignored, so a viewer sees only themselves until Posse is installed. A missing Posse still fails closed, the same as before.
- `/bluemapauth status` lists `Posse` where it listed `Mayor`.
- The soft dependency in `paper-plugin.yml` is now `Posse`.

## Installing over 0.2.3

Install it together with Posse 0.11.0. Follow Posse's order for renaming permissions first. With the server stopped, swap in `BlueMapAuth-0.3.0.jar`. Nothing in BlueMapAuth's own config changes.

## Tested

Unit and HTTP tests pass. Bots on throwaway Paper 26.1.2, 26.2 and 26.3 servers with the real BlueMap 5.29, LuckPerms 5.5, Posse 0.11.0 and WelcomeWagon 0.7.0 (27/27 each; 26.2 and 26.3 through ViaVersion and ViaBackwards with a 1.21.11 bot). The fail-closed run, with no Posse and no LuckPerms and an old Mayor 0.8.0 jar installed, passed 8/8 on 26.1.2: the in-game viewer sees only themselves. Not run in a real game client, and not run on a live server.
