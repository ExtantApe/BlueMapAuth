A security fix from the review of the map's public address (K70, 2026-11-24). Install it before the map is reachable from outside.

## What changed

- **Only an exact list of paths is passed to BlueMap:** the map page, `/settings.json`, `/assets/...`, `/lang/...`, a few icon files, and `/maps/<map>/...` for maps the viewer may see. Matching is case-sensitive. Anything else is "not found".
- **Paths BlueMap would read differently are refused:** any percent-encoding, backslash, empty segment, or `.` or `..` segment. Before, a signed-in player could reach a map they weren't allowed to see, and its live player list, by encoding a letter (`/%6Daps/...`), adding `/./` or changing the capitals. BlueMap decodes and tidies paths, and the Mac's disk ignores capitals.
- **Live data:** `live/players.json` is still filtered by who the viewer may see. `live/markers.json` now answers with no markers, because markers can carry positions Mayor hasn't checked. The live event stream and anything else under `live/` isn't passed on.
- **Map files are no longer cached for 5 minutes.** Each request is checked against the session, so a shared browser doesn't keep showing the map after sign-out.
- **Sign-in tries from IPv6 are counted per /64**, so a few addresses can't use up the limit.
- **A malformed hand-off link is answered "That link didn't work"** (403) instead of a server error.

## Installing over 0.2.0

With the server stopped, swap in `BlueMapAuth-0.2.1.jar`. Nothing else changes, and signed-in browsers stay signed in.

## Tested

31 unit and HTTP tests, including every path variant from the review. Bots on a throwaway Paper 26.1.2 server with the real BlueMap 5.29, LuckPerms, Mayor 0.8.0 and WelcomeWagon 0.6.1: 27/27 direct, and 28/28 with a throwaway Caddy in front running the staged map site block. The run without Mayor and LuckPerms passed 8/8 (fail closed). The encoded, dot and capitalised paths and the live stream were sent exactly as written and none reached a hidden map or live data. Not yet behind the real public address.
