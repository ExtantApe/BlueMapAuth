Mapkeeper is now BlueMapAuth (D194), so people looking for BlueMap add-ons find it. Nothing else changed in how it works.

## Upgrading

- Swap `Mapkeeper-0.1.0.jar` for `BlueMapAuth-0.2.0.jar` with the server stopped.
- On first start, BlueMapAuth copies `plugins/Mapkeeper/` to `plugins/BlueMapAuth/` if that doesn't exist yet. The old folder stays as it was.
- For 0.2.x only, `/mapkeeper` still works and `mapkeeper.admin` still grants `bluemapauth.admin`.
- The map's cookie has a new name, so anyone signed in to the map signs in once more through Latchkey.

## Tested

Unit and HTTP tests pass. The carry-over was checked on a throwaway server.
