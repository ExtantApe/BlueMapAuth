A new name (D194), so people looking for BlueMap add-ons find it. Nothing else changed in how it works.

## Installing over the previous version

With the server stopped:
1. Rename its plugin folder to `plugins/BlueMapAuth`.
2. Grant `bluemapauth.admin` in place of its old permission.
3. Swap in `BlueMapAuth-0.2.0.jar`.

Anyone signed in to the map signs in once more through Latchkey, because the map's cookie has a new name.

## Tested

Unit and HTTP tests pass. It finds WelcomeWagon and Mayor by their new names, so install it together with WelcomeWagon 0.6.0 and Mayor 0.5.0.
